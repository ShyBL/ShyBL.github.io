# Twitch Overlay in Unity
A suite of live stream overlays built in Unity for Twitch creator [dogxwillxhuntx](https://www.twitch.tv/dogxwillxhuntx/).
<br>
Developed and iterated multiple overlay versions across the lifetime of the channel, growing in complexity with each version. Features range from animated HUD elements to live chat interaction and in-stream mini-games driven by viewer participation.

## Key Features
- Multiple overlay versions developed and deployed over time
- Live Twitch chat integration for real-time viewer interaction
- In-stream mini-games driven by chat commands
- OBS integration for seamless broadcast compatibility
- Animated HUD elements and dynamic on-screen graphics
