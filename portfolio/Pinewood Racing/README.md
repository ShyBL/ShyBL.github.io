# Pinewood Racing
A racing game built around custom-made wooden cars, inspired by the classic American Scouts Pinewood Derby tradition.
<br>
Joined the project as UI/UX Designer and led a full redesign of the game's interface. Responsibilities spanned the complete HUD — speed and performance gauges, lap timers, and live track position tracking — as well as all menu and screen layouts across the game.

## Key Features
- Full UI/UX redesign across all game screens
- Custom HUD with speed gauges, lap timer, and track position tracking
- Visual style inspired by classic Pinewood Derby racing culture
- Cohesive design system applied from menus to in-race interface
